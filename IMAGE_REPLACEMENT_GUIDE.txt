GOOGLE DRIVE METHOD
-------------------
1. Upload your image to Google Drive.
2. Right-click > Share.
3. Set General access to "Anyone with the link" > Viewer.
4. Copy the Drive link.
5. Take the file ID from the link.
6. Put it into this format:

https://drive.google.com/uc?export=view&id=YOUR_FILE_ID

Example:
https://drive.google.com/uc?export=view&id=1AbCdEfGhIjKlMnOp

Then replace only the matching URL in image-links.js.

IMPORTANT
---------
Keep image-links.js in the SAME folder as the HTML file.
When uploading the website to hosting, upload both files together.
